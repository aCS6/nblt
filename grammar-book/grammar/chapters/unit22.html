B Grammar

The Passive

1 The passive: form

The active shows what something does. The passive = a form of be + past participle. The subject of the passive is the object of the active verb.

TensePassive form (subject: The union)
present simpleis run
present continuousis being run
past simplewas run
past continuouswas being run
present perfecthas been run
past perfecthad been run
going tois going to be run
willwill be run
infinitiveis to be run
-ing formbeing run
used toused to be run
modalsshould be run
need to / have toneeds / has to be run
need + -ingneeds running
⚠ We cannot use the passive with intransitive verbs: He arrived. (NOT He was arrived.)

2 The passive: use

  • When the object is more important than the subject, or the agent is obvious, unknown or unimportant:
    All applications are processed on the spot.
  • In formal writing to make it less personal:
    You are advised to return the application form within three days.
  • When describing a process:
    The union is run by seven executive officers who are elected by students.
  • To create a 'zigzag' pattern — repeating the end of one clause as the beginning of the next using the passive.
⚠ Do not use the passive for natural/biological processes: Plants take up carbon dioxide from the air. (NOT Carbon dioxide is taken up by plants. in this context)

3 Reporting with passive verbs

We use reporting passives in two main patterns:

  • it + passive verb + that-clause (agree, announce, argue, believe, claim, decide, expect, feel, know, report, say, suggest, think…):
    It was felt that the facilities were in need of renovation.
  • subject + passive verb + to-infinitive (ask, believe, consider, estimate, expect, feel, know, report, say, see, think…):
    Our sports facilities are said to be among the best in the country.
    This building is believed to be the oldest in the town.

4 Have something done

have + object + past participle means someone else does something for us:

You'll need to have your photo taken. (= someone takes it for you)

Informal: get + past participle: I got my photo taken yesterday.

5 Need + -ing

need + -ing can be used as an alternative to the passive:

Some facilities need improving around the campus.

(= Some facilities need to be improved)

The diagram below shows how fruit is canned.

Summarise the information by selecting and reporting the main features, and make comparisons where relevant.

Write at least 150 words.

Fruit canning process (15 stages):
Hand Picking → Transporting → Washing → Quality checking → Cold storing → Weighing/grading → Peeling → Coring/slicing → Canning → Sealing → Cooking/sterilizing → Cooling → Labelling → Storage → Despatch

Model answer

The diagram shows how fresh fruit is canned. First the fruit is picked from trees by hand. It is then transported to the cannery by large trucks. At the cannery the fruit is washed and quality checked, and any poor quality fruit is rejected. The good quality fruit is put into cold storage. When it is ready for canning the fruit is weighed and graded. The grading ensures that fruit of a similar size is kept together. After this the fruit is peeled and the cores are removed. It is then sliced into the required sizes and put into cans. Juice or syrup is also added to the cans. Once the cans have been filled they are sealed and cooked over heat to ensure that the cans are sterilized. When the cans are cool, a label is attached and they are placed into storage. The canned fruit is now ready to be despatched to supermarkets and sold.
